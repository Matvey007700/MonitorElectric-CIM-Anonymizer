# CIM XML Anonymizer

## Описание проекта

Проект разработан в рамках хакатона Monitor Electric.

Цель проекта — разработка программы для автоматизированного обезличивания моделей CIM, представленных в формате RDF/XML, с сохранением структуры модели и связей между объектами.

## Основные возможности

- Обработка CIM-моделей в формате XML.
- Обезличивание идентификаторов и названий объектов.
- Обработка чувствительных текстовых полей.
- Сохранение структуры XML.
- Формирование отчёта о результатах обработки.
- Проверка целостности ссылок между объектами.

## Описание файлов

| Файл | Назначение |
|---|---|
| `anonymize_cim.py` | Основной скрипт обезличивания CIM/XML |
| `compare_xml.py` | Сравнение количества объектов и ссылок в исходной и обработанной моделях |
| `check_references.py` | Проверка внутренних ссылок между объектами |
| `check_sensitive.py` | Проверка изменения выбранных чувствительных текстовых полей |
| `check_structure.py` | Сравнение распределения типов объектов и проверка дубликатов |
| `output_anonymized.xml` | Результат обработки (большой файл, для GitHub используется Git LFS) |
| `output_anonymized.xml.report.json` | Отчёт со статистикой обезличивания |
| `requirements.txt` | Список необходимых Python-библиотек |

**Статус:** код и отчёт опубликованы. Большой файл `output_anonymized.xml` ещё не загружен: для него необходима отдельная загрузка через Git LFS. Исходный `input.xml` не публикуется.

## Запуск программы

Установка зависимости:

```bash
python -m pip install -r requirements.txt
```

Запуск обезличивания:

```bash
python anonymize_cim.py input.xml output_anonymized.xml
```

Запуск проверок:

```bash
python compare_xml.py
python check_references.py
python check_sensitive.py
python check_structure.py
```

## Примечание

Результаты проверок подтверждают сохранение ряда структурных характеристик модели. Полная проверка отсутствия конфиденциальных данных и соответствия всем требованиям обезличивания требует дополнительной проверки.

## Условия воспроизведения и ограничения

Исходная модель `input.xml` не распространяется. Для запуска сравнительных проверок необходимо локально разместить разрешённую исходную модель и результат обработки рядом со скриптами. `check_references.py` требует только результат.

Программа заменяет внутренние `rdf:about` и `rdf:resource`, начинающиеся с `#`, и выбранные текстовые поля. Внешние ссылки сохраняются. Используется детерминированное хеширование без секретного ключа; устойчивость к повторной идентификации не гарантируется. Проверки не доказывают полную эквивалентность RDF-графов или отсутствие конфиденциальных данных.

По ранее полученным результатам локальных проверок: в каждой модели 5 656 933 атрибута `rdf:resource`, из них в результате 5 455 104 внутренних ссылок; проверено 613 559 выбранных текстовых полей, неизменённых — 0. XML содержит 9 014 537 элементов. Эти показатели относятся к конкретной обработанной модели.

Перед открытой публикацией необходимо убедиться, что условия задания разрешают распространение обработанной модели.
